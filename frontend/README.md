# ARC ERP frontend

Frontend React limpo para o rebuild do ARC ERP.

## Comandos

- `npm run dev` inicia o Vite em modo desenvolvimento.
- `npm run build` valida TypeScript e gera a build de produção.
- `npm run lint` executa o ESLint.

As chamadas locais para a API devem usar `/api`; o Vite e o Nginx fazem o proxy para o backend.
